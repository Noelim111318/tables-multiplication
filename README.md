# ⭐ Tables de Multiplication PWA

App pour s'entraîner aux tables de multiplication. Installable, offline, clavier personnalisé.

**Lien**: https://Noelim111318.github.io/tables-multiplication/

## Démarrage local
```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Fichiers essentiels
- `index.html` - Structure
- `app.css` - Styles  
- `app.js` - Logique
- `service-worker.js` - Offline
- `manifest.json` - PWA config
- `icons/` - Icons PWA

## Installer sur mobile
- **Android**: Menu → Install App
- **iOS**: Partage → Ajouter à l'écran d'accueil
